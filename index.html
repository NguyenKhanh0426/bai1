PM1 - Bài Cuối Kì

Võ Nguyên Khánh

Đây là trang web minh họa cho bài tập cuối kì môn PM1. Trang được xây dựng bằng HTML & CSS và triển khai trên GitHub Pages.

Nội dung chính:

  • Quản lý mã nguồn bằng Git & GitHub
  • Triển khai website tĩnh trên GitHub Pages
  • Cập nhật nội dung thông qua commit & push

Website này dùng để trình bày kết quả thực hành và hiểu biết về quy trình làm việc với GitHub.
